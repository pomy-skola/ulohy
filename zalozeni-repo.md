# Založení repozitáře

*odhadovaný čas: ~5 min. + přečtení zadání*

Založíte repozitář na portále Github, pod vlastním účtem.

- Pokud účet na Github nemáte, založte si jej, ale použijte školní e-mail. Pokud tam již účet máte a chcete jej používat i pro školní potřeby, připojte si školní e-mail k svému účtu.
- Repozitář bude spravovat skripty psané v jazyce Python, proto je vhodné předem nastavit soubor `.gitignore` s typickými hodnotami právě pro Python.
- Součástí repozitáře bude `README.md`, zatím prázdné.
- Vytvořený repozitář si "naklonujte" do počítače.
